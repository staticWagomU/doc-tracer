# スキャン処理詳細設計書

## 1. 処理フロー

```
runScan()
    │
    ├─── !codeOnly ──► scanDocs()
    │                      │
    │                      ├── filepath.Walk()
    │                      │       │
    │                      │       ▼
    │                      │   ┌───────────────┐
    │                      │   │ .md ファイル?  │
    │                      │   └───────┬───────┘
    │                      │           │ Yes
    │                      │           ▼
    │                      │   parseFrontMatter()
    │                      │           │
    │                      │           ▼
    │                      │   UpsertNode() + UpsertEdge()
    │                      │
    │
    └─── !docsOnly ──► scanCode()
                           │
                           ├── filepath.Walk()
                           │       │
                           │       ▼
                           │   ┌───────────────────┐
                           │   │ 対象拡張子?        │
                           │   │ .vue/.ts/.php     │
                           │   └───────┬───────────┘
                           │           │ Yes
                           │           ▼
                           │   parseXxxFile()
                           │           │
                           │           ▼
                           │   UpsertNode() + UpsertEdge()
```

---

## 2. ドキュメントスキャン

### 2.1 対象ファイル

- パス: `docs/` ディレクトリ配下
- 拡張子: `.md`
- 除外: `99_アーカイブ/`, `90_作業ログ/`

### 2.2 YAMLフロントマター解析

```go
type TraceInfo struct {
    ID         string   `yaml:"id"`
    Implements []string `yaml:"implements"`
    Uses       []string `yaml:"uses"`
    Parent     []string `yaml:"parent"`
}

type FrontMatter struct {
    Trace TraceInfo `yaml:"trace"`
}
```

### 2.3 エッジ生成ルール

| フィールド | 生成されるエッジ | 方向 |
|-----------|----------------|------|
| `parent` | `contains` | 親 → 自分 |
| `children` | `contains` | 自分 → 子 |
| `implements` | `implements` | 自分 → 対象 |
| `uses` | `uses` | 自分 → 対象 |

---

## 3. コードスキャン

### 3.1 対象ファイル

| 拡張子 | パーサー |
|-------|---------|
| `.vue` | parseVueFile() |
| `.ts`, `.tsx`, `.js` | parseTypeScriptFile() |
| `.php` | parsePhpFile() |

### 3.2 除外ディレクトリ

- `node_modules/`
- `vendor/`
- `.git/`
- `dist/`
- `build/`

---

## 4. Vueファイル解析

### 4.1 検出対象

1. **import文**: `import Xxx from './Xxx.vue'`
2. **テンプレート内コンポーネント**: `<ComponentName />`, `<component-name>`
3. **API呼び出し**: `$fetch()`, `useFetch()`, `fetch()`

### 4.2 エッジ生成

| 検出パターン | 関係タイプ |
|------------|----------|
| import .vue | `contains` |
| テンプレート内タグ | `contains` |
| API呼び出し | `calls` |

### 4.3 HTMLタグ除外リスト

`div`, `span`, `p`, `a`, `img`, `ul`, `ol`, `li`, `h1`-`h6`, `table`, `tr`, `td`, `th`, `form`, `input`, `button`, `label`, `select`, `option`, `textarea`, `section`, `header`, `footer`, `nav`, `main`, `article`, `aside`, `figure`, `template`, `slot`, `component`, `transition`, `svg`, `path`, `rect`, `circle`, `line`, `use`, `defs`, `g`, `text`, `tspan`

---

## 5. PHPファイル解析

### 5.1 コントローラー検出

- 条件: パスに `Controller` を含む
- ノードタイプ: `controller`
- ルート定義から `api` ノード生成

### 5.2 モデル検出

- 条件: パスに `Models` または `Model.php` を含む
- ノードタイプ: `model`
- `$table` プロパティから `db_table` ノード生成

---

## 6. ID生成規則

### 6.1 ドキュメント

```
doc:docs/03_基本設計/認証設計書.md
```

パスを正規化（`/docs/` からの相対パス）。

### 6.2 コンポーネント

```
component:LoginForm
```

ファイル名から `.vue` を除去。

### 6.3 その他

```
store:useAuthStore
composable:useAuth
module:utils
controller:UserController
model:User
db:users
api:GET /api/v1/users
```
