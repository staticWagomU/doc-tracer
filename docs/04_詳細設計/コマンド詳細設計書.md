# コマンド詳細設計書

## 1. serve コマンド

### 1.1 処理フロー

```
runServe()
    │
    ├── db.Open()
    │
    ├── http.HandleFunc("/api/graph", handleGraph)
    │
    ├── http.HandleFunc("/api/impact", handleImpact)
    │
    ├── http.Handle("/", 埋め込みHTML)
    │
    └── http.ListenAndServe()
```

### 1.2 APIエンドポイント

#### GET /api/graph

全ノード・エッジを返却。

**レスポンス**:
```json
{
  "nodes": [
    {
      "id": "doc:docs/01_要件定義/要件定義書.md",
      "type": "document",
      "name": "要件定義書.md",
      "file_path": "docs/01_要件定義/要件定義書.md"
    }
  ],
  "edges": [
    {
      "from_id": "doc:docs/01_要件定義/要件定義書.md",
      "to_id": "doc:docs/02_仕様書/機能仕様書.md",
      "relation": "contains"
    }
  ]
}
```

#### GET /api/impact?file=xxx

影響を受けるドキュメントを返却。

**パラメータ**: `file` - ファイルパス

**レスポンス**:
```json
[
  {
    "id": "doc:docs/03_基本設計/xxx.md",
    "type": "document",
    "name": "xxx.md",
    "file_path": "docs/03_基本設計/xxx.md"
  }
]
```

## 2. check コマンド

### 2.1 処理フロー

```
runCheck()
    │
    ├── db.Open()
    │
    ├── CheckBrokenLinks()
    │       │
    │       └── リンク切れがあれば表示
    │
    ├── GetOrphanedDocs()
    │       │
    │       └── 孤立ドキュメントがあれば表示
    │
    ├── 統計情報表示
    │       │
    │       ├── ノードタイプ別集計
    │       │
    │       └── 関係タイプ別集計
    │
    └── 問題があればエラー終了
```

### 2.2 チェック項目

| チェック | クエリ | 説明 |
|---------|-------|------|
| リンク切れ | edges LEFT JOIN nodes | from_id または to_id が存在しない |
| 孤立 | nodes LEFT JOIN edges | どのエッジにも含まれない document |

## 3. impact コマンド

### 3.1 処理フロー

```
runImpact()
    │
    ├── db.Open()
    │
    ├── GetImpactedDocs(filePath)
    │       │
    │       └── 再帰CTEで上方向トレース
    │
    └── 結果表示（テキスト or JSON）
```

### 3.2 再帰CTEの動作

```
起点ノード（depth=0）
    ↓
エッジを逆方向（to_id → from_id）に辿る
    ↓
depth < 10 まで再帰
    ↓
type = 'document' のみ抽出
```

**制限**: 最大深度10（無限ループ防止）

## 4. Web UI

### 4.1 技術構成

- D3.js v7: グラフ描画
- Force Simulation: ノード配置

| 機能 | 実装 |

| 検索 | input → ノードフィルタリング |
| 影響表示 | /api/impact 呼び出し |
