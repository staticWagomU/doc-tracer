# doc-tracer アーキテクチャ設計書

## 1. 全体構成

```
┌─────────────────────────────────────────────────────────────┐
│                        CLI Layer                            │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐           │
│  │  scan   │ │  serve  │ │  check  │ │ impact  │           │
│  └────┬────┘ └────┬────┘ └────┬────┘ └────┬────┘           │
└───────┼───────────┼───────────┼───────────┼─────────────────┘
        │           │           │           │
┌───────┼───────────┼───────────┼───────────┼─────────────────┐
│       ▼           ▼           ▼           ▼                 │
│  ┌─────────────────────────────────────────────┐            │
│  │              Business Logic                  │            │
│  │  - Document Parser (YAML frontmatter)       │            │
│  │  - Code Analyzer (Vue, TS, PHP)             │            │
│  │  - Impact Calculator                         │            │
│  └─────────────────────┬───────────────────────┘            │
│                        │                                     │
│  ┌─────────────────────▼───────────────────────┐            │
│  │              Data Layer (SQLite)            │            │
│  │  - nodes table                              │            │
│  │  - edges table                              │            │
│  │  - scan_history table                       │            │
│  └─────────────────────────────────────────────┘            │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 技術スタック

| 層 | 技術 | 理由 |
|----|------|------|
| CLI | Cobra | Go標準のCLIフレームワーク |
| DB | SQLite (modernc.org/sqlite) | Pure Go、外部依存なし |
| Web UI | D3.js | グラフ可視化に特化 |
| 埋め込み | go:embed | 単一バイナリ配布 |

---

## 3. ディレクトリ構成

```
doc-tracer/
├── main.go              # エントリポイント
├── cmd/
│   ├── root.go          # ルートコマンド、グローバルフラグ
│   ├── scan.go          # スキャンコマンド
│   ├── serve.go         # Webサーバー
│   ├── check.go         # 整合性チェック
│   ├── impact.go        # 影響範囲検索
│   └── web/
│       └── index.html   # Web UI（埋め込み）
└── internal/
    └── db/
        └── schema.go    # DBスキーマ、CRUD
```

## 4. データフロー

### 4.1 スキャン

```
ファイルシステム
     │
     ▼
┌──────────────────┐
│   File Walker    │  ← docs/, src/ を再帰的に走査
└────────┬─────────┘
         │
    ┌────┴────┐
    ▼         ▼
┌───────┐  ┌───────┐
│  .md  │  │ .vue  │
│ Parser│  │ .ts   │
│       │  │ .php  │
│       │  │ Parser│
└───┬───┘  └───┬───┘
    │          │
    ▼          ▼
┌─────────────────┐
│   SQLite DB     │
│  nodes + edges  │
└─────────────────┘
```
