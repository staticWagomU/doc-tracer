# doc-tracer データモデル設計書

## 1. 概要

doc-tracerは、トレーサビリティ情報をSQLite DBに永続化します。

---

## 3. テーブル定義

### 3.1 nodes

ノード（ドキュメント、コード要素）を格納。

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| id | TEXT | PRIMARY KEY | 一意識別子（例: `doc:docs/xxx.md`） |
| type | TEXT | NOT NULL | ノードタイプ |
| name | TEXT | NOT NULL | 表示名 |
| file_path | TEXT | | ファイルパス |
| file_hash | TEXT | | SHA256ハッシュ（変更検知用） |
| line_start | INTEGER | | 開始行（コード要素） |
| line_end | INTEGER | | 終了行 |
| metadata | TEXT | | 追加情報（JSON） |
| updated_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 更新日時 |

**ノードタイプ一覧**:
- `document`: Markdownドキュメント
- `component`: Vueコンポーネント
- `api`: APIエンドポイント
- `controller`: PHPコントローラー
- `model`: Eloquentモデル
- `store`: Piniaストア
- `composable`: Vue Composable
- `module`: TypeScriptモジュール
- `db_table`: DBテーブル

### 3.2 edges

エッジ（ノード間の関係）を格納。

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自動採番ID |
| from_id | TEXT | NOT NULL, FK | 起点ノードID |
| to_id | TEXT | NOT NULL, FK | 終点ノードID |
| relation | TEXT | NOT NULL | 関係タイプ |
| source | TEXT | DEFAULT 'auto' | `auto` or `manual` |
| defined_in | TEXT | | 定義元ファイル |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 作成日時 |

**UNIQUE制約**: `(from_id, to_id, relation)`

**関係タイプ一覧**:
- `contains`: 親子関係（階層構造）
- `implements`: 実装関係
- `uses`: 使用・参照関係
- `calls`: API呼び出し

### 3.3 scan_history

スキャン履歴（増分スキャン用）。

| カラム | 型 | 制約 | 説明 |
|--------|-----|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自動採番ID |
| file_path | TEXT | NOT NULL | ファイルパス |
| file_hash | TEXT | NOT NULL | スキャン時ハッシュ |
| scanned_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | スキャン日時 |

| テーブル | インデックス | 目的 |

| edges | idx_edges_to_id | 終点からの検索（逆引き） |

## 5. クエリパターン

### 5.1 影響範囲検索（再帰CTE）

```sql
WITH RECURSIVE impact_chain AS (
    -- 起点: 指定ファイルのノード
    SELECT n.id, n.type, n.name, n.file_path, 0 as depth
    FROM nodes n
    WHERE n.file_path = ?

    UNION

    -- 再帰: エッジを逆方向に辿る
    SELECT n.id, n.type, n.name, n.file_path, ic.depth + 1
    FROM nodes n
    JOIN edges e ON e.from_id = n.id
    JOIN impact_chain ic ON e.to_id = ic.id
    WHERE ic.depth < 10
)
SELECT DISTINCT id, type, name, file_path
FROM impact_chain
WHERE type = 'document'
ORDER BY depth
```

### 5.2 リンク切れ検出

```sql
SELECT e.*
FROM edges e
LEFT JOIN nodes n1 ON e.from_id = n1.id
LEFT JOIN nodes n2 ON e.to_id = n2.id
WHERE n1.id IS NULL OR n2.id IS NULL
```

### 5.3 孤立ドキュメント検出

```sql
SELECT n.*
FROM nodes n
LEFT JOIN edges e ON n.id = e.from_id OR n.id = e.to_id
WHERE n.type = 'document' AND e.id IS NULL
```
