# check コマンド プログラム設計書

## 1. ファイル構成

```
cmd/check.go
```

---

## 2. 主要関数

### 2.1 runCheck

```go
func runCheck(cmd *cobra.Command, args []string) error
```

**責務**: 整合性チェックの実行

**処理**:
1. DB接続
2. リンク切れチェック
3. 孤立ドキュメントチェック
4. 統計情報表示
5. 問題があればエラー返却
