# doc-tracer 機能仕様書

## 1. 概要

doc-tracerは、ドキュメントとコードの関係を**有向グラフ**として表現し、双方向トレーサビリティを実現するCLIツールです。

---

## 2. 核心的アイデア

### 2.1 グラフによる関係性の明示

```
[要件定義] → [仕様書] → [基本設計] → [詳細設計] → [プログラム設計] → [コード]
     ↑                                                                    ↓
     └──────────────── 影響範囲の逆引き ←─────────────────────────────────┘
```

- **ノード**: ドキュメント、コンポーネント、API、DBテーブルなど
- **エッジ**: contains（親子）、implements（実装）、uses（使用）、calls（呼び出し）

### 2.2 2つの情報源

1. **YAMLフロントマター（手動）**: ドキュメント間の階層関係を明示的に記述
2. **静的解析（自動）**: コード内のimport文、API呼び出しを自動検出

---

## 3. 5層ドキュメント構造

```
01_要件定義/        # WHY - なぜ作るのか
02_仕様書/          # WHAT - 何を作るのか
03_基本設計/        # HOW（概要）- どう作るか
04_詳細設計/        # HOW（詳細）
05_プログラム設計/  # 実装設計
```

---

## 4. YAMLフロントマター仕様

### 4.1 構造

```yaml
---
trace:
  id: doc:docs/03_基本設計/認証設計書.md
  parent:
    - doc:docs/02_仕様書/認証仕様書.md
  children:
    - doc:docs/04_詳細設計/ログイン詳細設計.md
  implements:
    - doc:docs/01_要件定義/機能要件定義書.md
  uses:
    - component:LoginForm
    - api:/api/v1/auth/login
---
```

### 4.2 フィールド定義

| フィールド | 説明 | 生成されるエッジ |
|-----------|------|-----------------|
| `id` | このドキュメントの一意識別子 | - |
| `parent` | 親ドキュメントのID | 親 → 自分 (`contains`) |
| `children` | 子ドキュメントのID | 自分 → 子 (`contains`) |
| `implements` | 実装元のID | 自分 → 対象 (`implements`) |
| `uses` | 使用するコード要素のID | 自分 → 対象 (`uses`) |

### 4.3 ID命名規則

| プレフィックス | 対象 | 例 |
|--------------|------|-----|
| `doc:` | ドキュメント | `doc:docs/03_基本設計/認証設計書.md` |
| `component:` | Vueコンポーネント | `component:LoginForm` |
| `api:` | APIエンドポイント | `api:/api/v1/users` |
| `controller:` | PHPコントローラー | `controller:UserController` |
| `model:` | Eloquentモデル | `model:User` |
| `store:` | Piniaストア | `store:useAuthStore` |
| `db:` | DBテーブル | `db:users` |

---

## 5. エッジ（関係）の種類

### 5.1 contains（包含）

親子関係。階層構造を表現。

- 生成条件: `parent` / `children` 定義、Vueテンプレート内コンポーネント使用

### 5.2 implements（実装）

下位層が上位層を実装する関係。

- 生成条件: `implements` 定義

### 5.3 uses（使用）

参照・依存関係。

- 生成条件: `uses` 定義、コード内import文

### 5.4 calls（呼び出し）

API呼び出し関係。

- 生成条件: `$fetch()`, `useFetch()`, `fetch()` 呼び出し

---

## 6. コマンド仕様

### 6.1 scan

```bash
doc-tracer scan [path] [--docs-only] [--code-only] [--db tracer.db]
```

### 6.2 serve

```bash
doc-tracer serve [--port 8080] [--db tracer.db]
```

### 6.3 check

```bash
doc-tracer check [--db tracer.db]
```

### 6.4 impact

```bash
doc-tracer impact <file> [--json] [--db tracer.db]
```
